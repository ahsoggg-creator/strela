## Strela 0.2.0 — программы, автозагрузка, процессы

Три новые вкладки и те же команды в `strela-cli`.

- **Программы.** Удаление в один клик — тихое (`msiexec /qn` или родной тихий режим), обычное или принудительное: Strela сама закрывает процессы и службы программы, мгновенно удаляет её папку и запись из списка. Затем **поиск следов** в файлах, реестре, автозагрузке, службах и задачах планировщика: надёжные совпадения отмечены сразу, вероятные нет; разделы реестра перед удалением сохраняются в `.reg`. Следы можно искать и у уже удалённой программы.
- **Автозагрузка.** Реестр (`Run`, `RunOnce`), папки «Автозагрузка», службы, задачи планировщика и скрытые точки входа (Winlogon, AppInit_DLLs, подмена запуска) в одном списке. Переключатель работает так же, как в диспетчере задач. Предупреждения о «битых» записях и запуске из «Загрузок».
- **Процессы.** Живая таблица (ЦП, память, ввод-вывод, дескрипторы, пользователь), дерево, командная строка, модули, завершение процесса и дерева, приостановка, приоритет. Критические процессы Windows защищены от завершения.
- Права администратора нужны только для чужих процессов, служб и задач: кнопка «Открыть от администратора» запускает отдельное окно с этими вкладками, основная копия остаётся без повышенных прав.
- `strela-cli`: `apps`, `uninstall`, `traces`, `startup`, `ps`, `kill`.

Ограничения: приложения из Microsoft Store в списке программ не показываются; принудительное удаление обходит деинсталлятор (для MSI-программ он всё равно вызывается через `msiexec`); поиск следов ищет по названию, а не «по смыслу». Подробности — в [README](https://github.com/ahsoggg-creator/strela#readme).

**Файлы релиза**

| Файл | Что это |
| --- | --- |
| `Strela-Setup.exe` | установщик: ставится в `%LOCALAPPDATA%\Programs\Strela`, права администратора не нужны (служба индексации — по желанию, один запрос прав) |
| `Strela.exe` | переносная версия (тот же файл; установить можно из настроек) |
| `strela-cli.exe` | консольная версия движка: `search`, `copy`, `move`, `delete`, `grep`, `largest` |
| `SHA256SUMS.txt` | контрольные суммы |

**Что важно знать**

- Меню «Strela ▸» — в классическом контекстном меню Проводника. В Windows 11 это «Показать дополнительные параметры» (Shift+F10). Пункт в верхнем меню Windows 11 не сделан: для него нужен подписанный пакет (sparse package) — см. README.
- Чтение MFT напрямую и журнал USN работают через службу `StrelaIndexer` (ставится по желанию, один запрос UAC). Без неё поиск идёт через обход папок и тоже быстрый.
- Исполняемые файлы не подписаны: SmartScreen может показать предупреждение «неизвестный издатель».
- Никакой телеметрии и сетевых запросов.

Подробности, измерения скорости и ограничения — в [README](https://github.com/ahsoggg-creator/strela#readme) и [docs/BENCHMARKS.md](https://github.com/ahsoggg-creator/strela/blob/main/docs/BENCHMARKS.md).
